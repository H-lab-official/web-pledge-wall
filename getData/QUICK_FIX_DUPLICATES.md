## 🛡️ ป้องกันการซ้ำในอนาคต

ระบบมี **logic ตรวจสอบซ้ำอัตโนมัติ** แล้ว:

```rust
// ตรวจสอบว่า ID มีอยู่แล้วหรือไม่
if !fetched_keys.contains(&key_value) {
    save_to_file(&item, &config.output_file);
    fetched_keys.insert(key_value);
}
```

**ไม่มีข้อมูลซ้ำอีกต่อไป!** ✅

## 💡 Tips

1. **เลือก Unique Key ให้ถูกต้อง:**
   - ใช้ `id` (แนะนำ! ⭐)
   - ไม่ควรใช้ `message` (อาจซ้ำได้)

2. **Backup อัตโนมัติ:**
   - สคริปต์จะสร้าง backup ทุกครั้ง
   - ไฟล์ backup: `data-backup-YYYY-MM-DD-HHMMSS.txt`

3. **ตรวจสอบผลลัพธ์:**
   - ดูจำนวนข้อมูลที่เหลือ
   - ถ้าน้อยเกินไป → ตรวจสอบ unique key
