# 🔧 แก้ปัญหาข้อมูลซ้ำ

## ❓ ทำไมข้อมูลถึงซ้ำ?

ข้อมูลอาจซ้ำเพราะ:
1. **ดึงข้อมูลก่อน logic ตรวจสอบซ้ำถูกสร้าง**
2. **Unique key ไม่ได้ถูกเลือกอย่างถูกต้อง**
3. **ไฟล์ถูกแก้ไขด้วยมือ**

---

## ✅ วิธีแก้ (มี 2 แบบ)

### วิธีที่ 1: ใช้ปุ่มใน UI (แนะนำ! ⭐)

1. **รัน Tauri App:**
   ```bash
   cd D:\PeeMee\getData\src-tauri
   cargo tauri dev
   ```

2. **ไปที่ Step 5 (สถิติการดึงข้อมูล)**

3. **คลิกปุ่ม "🗑️ ลบข้อมูลซ้ำ"**

4. **ยืนยันการลบ**

5. **เสร็จแล้ว!** ระบบจะ:
   - ✅ เก็บข้อมูลที่ไม่ซ้ำไว้
   - ❌ ลบข้อมูลซ้ำออก
   - 📊 แสดงจำนวนข้อมูลที่เหลือ

---

### วิธีที่ 2: ลบไฟล์แล้วเริ่มใหม่

1. **ลบไฟล์ data.txt:**
   ```bash
   cd D:\PeeMee\getData\src-tauri
   del data.txt
   ```

2. **รัน App อีกครั้ง:**
   ```bash
   cargo tauri dev
   ```

3. **ดึงข้อมูลใหม่** - ระบบจะไม่มีข้อมูลซ้ำอีกต่อไป

---

## 🛡️ ป้องกันไม่ให้ซ้ำในอนาคต

### Logic ตรวจสอบซ้ำทำงานอย่างไร:

1. **โหลด Unique Keys ที่มีอยู่แล้ว** (จากไฟล์ data.txt)
2. **เช็คข้อมูลใหม่** ว่า unique key มีอยู่แล้วหรือไม่
3. **บันทึกเฉพาะข้อมูลที่ไม่ซ้ำ**

### ตัวอย่าง Code (main.rs):

```rust
// โหลด keys ที่มีอยู่แล้ว
let mut fetched_keys = load_fetched_keys(&config.output_file, &config.unique_key);

for item in items {
    let key_value = extract_key_value(&item, &config.unique_key);
    
    // เช็คว่ามีอยู่แล้วหรือไม่
    if !fetched_keys.contains(&key_value) {
        save_to_file(&item, &config.output_file);
        fetched_keys.insert(key_value); // เพิ่ม key ใหม่
    }
}
```

## 💡 Tips

1. **เลือก Unique Key ให้ถูกต้อง:**
   - ใช้ `id` ถ้ามี (แนะนำ! ⭐)
   - ใช้ `message` ถ้าไม่มี id (อาจซ้ำได้)

2. **ตรวจสอบข้อมูลเป็นประจำ:**
   - ดูจำนวนข้อมูลใน Step 5
   - ถ้าเพิ่มไม่เท่าที่ควร → มีข้อมูลซ้ำ

3. **Backup ไฟล์ก่อนลบ:**
   ```bash
   copy data.txt data-backup.txt
   ```

## 🆘 เจอปัญหา?

### ❌ "ไม่พบไฟล์"
- ตรวจสอบว่าไฟล์อยู่ที่ `getData/src-tauri/data.txt`

### ❌ "Unique key ไม่ถูกต้อง"
- ตรวจสอบว่า field ที่เลือกมีอยู่จริงในข้อมูล
- ลองใช้ field อื่นแทน

### ❌ "ข้อมูลยังซ้ำอยู่"
- ลองรีสตาร์ท app แล้วลบซ้ำอีกครั้ง
- หรือลบไฟล์ data.txt แล้วเริ่มใหม่
